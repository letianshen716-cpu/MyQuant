# 实验报告：多因子横截面清洗与入库节点

**时间**：2026-08
**节点目标**：完成基础价量因子计算，消除极端值和风格偏误，构建标准因子库。

## 1. 核心处理流程 (Pipeline)
针对提取到的原始因子，本阶段在每日横截面上依次执行以下标准步骤：
1. **缺失值填充**：按行业分组的中位数进行填充。
2. **去极值 (Winsorization)**：采用绝对中位差法 (MAD)，阈值设定为 `n=3.0` 倍。
3. **初步标准化 (Z-score)**：转为均值为0，标准差为1的分布。
4. **正交中性化 (Neutralization)**：采用 OLS 线性回归，以因子值为因变量，对数市值和行业哑变量为自变量，取残差作为中性化后的纯净因子。
5. **二次标准化**：确保截面量纲一致。

## 2. 数据落盘机制
为解决 CSV 文件读取缓慢的问题，自行开发了 `FactorDatabase`。
* 底层数据采用 `PyArrow` 引擎存为按日分区的 `.parquet` 格式。
* 引入 `SQLite` 作为元数据库，记录因子的版本号(version)、生成时间与描述，实现因子的版本追溯。

## 3. 下一步计划
目前已成功入库 `mom_20`、`volatility_20` 等因子。下一节点计划编写回测脚本，计算上述因子的 IC/IR 值并进行多空分组收益率评价。
