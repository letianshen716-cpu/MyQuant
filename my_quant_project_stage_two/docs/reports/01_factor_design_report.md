# 节点 1：基本面/技术面/另类因子设计逻辑与数学定义报告

## 1. 研究背景与设计原则
本阶段的核心任务是构建具备明确金融学与行为金融学逻辑的量化因子库。所有因子的设计均遵循“逻辑可解释、数据可获得、计算可复现”的三大原则。首批构建的基准因子池涵盖技术面（量价特征）与基本面（财务特征）两大维度。

## 2. 技术面因子 (Technical Factors) 逻辑与定义
技术面因子主要捕捉市场微观结构中的投资者行为偏差（如过度反应、羊群效应等）。

### 2.1 动量/反转因子 (Momentum/Reversal)
*   **因子名称**：`mom_10d` (10日反转), `mom_20d` (20日反转)
*   **计算公式**：
    $$R_{t, N} = \frac{P_t}{P_{t-N}} - 1$$
    其中，$P_t$ 为 $t$ 日收盘价，$N$ 为时间窗口（10 或 20）。
*   **经济学逻辑**：A 股市场在短期（1个月以内）存在显著的**动量反转效应**。前期涨幅过大的股票往往面临获利盘抛压，而前期超跌的股票存在均值回归的动能。预期 Alpha 方向为**负向**。

### 2.2 波动率因子 (Volatility)
*   **因子名称**：`volatility_20d`
*   **计算公式**：
    $$\sigma_{20} = \sqrt{\frac{1}{19} \sum_{i=0}^{19} (R_{t-i} - \bar{R})^2}$$
    其中，$R$ 为每日对数收益率。
*   **经济学逻辑**：“低波动异常 (Low Volatility Anomaly)”。高波动股票通常伴随投机资金炒作，长期来看存在“博傻”特征，持有高波动股票的夏普比率往往极低。预期 Alpha 方向为**负向**。

### 2.3 流动性/量价因子 (Liquidity)
*   **因子名称**：`volume_mean_20d` (20日平均成交量)
*   **计算公式**：过去 20 个交易日的成交量（或换手率）的算术平均值。
*   **经济学逻辑**：“缩量溢价”。在缺乏增量资金的市场中，前期成交量极度萎缩、流动性枯竭的“冷门股”往往处于筹码锁定状态，稍微有资金点火即可产生巨大涨幅。预期 Alpha 方向为**负向**。

## 3. 基本面因子 (Fundamental Factors) 逻辑与定义
基本面因子旨在评估企业的内生盈利能力与安全边际。

### 3.1 盈利能力 (Profitability)
*   **因子名称**：`roe` (净资产收益率)
*   **计算公式**：
    $$ROE = \frac{Net\_Profit}{Total\_Equity}$$
*   **经济学逻辑**：衡量企业运用自有资本的效率，ROE 越高代表企业护城河与盈利能力越强。预期 Alpha 方向为**正向**。

### 3.2 估值水平 (Valuation)
*   **因子名称**：`ep` (盈利收益率，即 PE 的倒数)
*   **计算公式**：
    $$EP = \frac{Net\_Profit}{Market\_Cap}$$
*   **经济学逻辑**：采用 EP 而非 PE，是为了避免企业盈利为负或接近零时导致的指标畸变。EP 越高说明估值越便宜，安全边际越高。预期 Alpha 方向为**正向**。
