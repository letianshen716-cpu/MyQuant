# 节点 2：PIT防前视偏差、缺失值填补与生存偏差校正过程与结论

## 1. 数据清洗的核心痛点
在量化数据预处理中，财务数据的引入往往伴随着极高的风险。如果模型在 $t$ 日使用到了当时尚未公布的财务数据，就会产生“前视偏差 (Look-ahead Bias)”，导致回测呈现暴利，而实盘持续亏损。

## 2. 核心校正机制：PIT (Point-in-Time) 时序严格向后对齐
为彻底阻绝未来函数，系统引入了严格的 PIT 对齐引擎。

### 2.1 财务信息披露时间窗映射
我们根据 A 股交易所的法定财报披露截止日，强制推导每一份财报的“安全可用日 (Safe Date)”：
*   **一季报 (Q1)**：法定截至 04-30，系统映射至 **05-01** 可见。
*   **中报 (Q2)**：法定截至 08-31，系统映射至 **09-01** 可见。
*   **三季报 (Q3)**：法定截至 10-31，系统映射至 **11-01** 可见。
*   **年报 (Q4)**：法定截至次年 04-30，系统映射至 **次年 05-01** 可见。

### 2.2 拼接逻辑 (`Backward Merge`)
利用 Pandas 的 `merge_asof` 函数，指定 `direction='backward'`。在任何一个交易日截面，模型只会匹配该标的**在时间轴上最近且已经越过安全可用日**的那一份财报，确保了数据的绝对真实有效。

## 3. 缺失值 (NaN) 填补方案
由于财报披露周期不一致或部分个股停牌，因子宽表不可避免存在缺失值。
*   **第一级填补**：在每个交易日横截面上，优先计算该个股所在**申万二级/通达信行业板块的中位数 (Industry Median)** 进行填补。此举最大限度地保留了同类公司的基本面与量价特征。
*   **第二级兜底**：若整个行业数据缺失，则使用当日全市场截面的中位数进行兜底。

## 4. 异常值与生存偏差过滤
*   对于明显违背常理的数据（如 $ROE > 1000\%$ 或市值为负），程序在读取阶段已作强制置空 (NaN) 处理，随后进入中位数填补流水线。
*   停牌股票 (当期 Volume 为 0) 默认保留上一个交易日的特征值，但在后续回测引擎中会被施加“禁止买入”约束。
