# 阶段三：单因子有效性检验、对称正交化与异质性分析报告

## 1. 实验方法与评价体系
* **去极值与标准化**：截面三倍中位差（$3 \times 1.4826 \times \text{MAD}$）去极值 + 截面 Z-score 标准化。
* **共线性处理**：对称正交化变换（Symmetric Orthogonalization），消除因子互相关性。
* **特征筛选**：LassoCV 正则化惩罚回归。
* **评价指标**：Spearman Rank IC 均值、信息比率（IR）、IC 胜率、五分组（G1~G5）分层回测收益及多空收益差（扣除 0.3% 摩擦成本）。

## 3. 核心实证规律总结

### 3.1 缩量与低波效应主导 A 股 Alpha
* **成交量反转强劲**：`amt_mean_20d` 的 IC 均值达 0.0819，多空收益差达 +1.82x，表明散户情绪驱动下，前期过度放量标的易见顶，而缩量滞涨个股补涨动力充足。
* **低波异象显著**：`volatility` 因子 IC 为 0.0709，低波动资产有效规避了情绪踩踏期的剧烈回撤。

### 3.2 动量周期的期限衰减特征
* 10 日反转（IC 0.0472 / 胜率 68.75%）全面强于 20 日反转（IC 0.0367 / 胜率 60.76%），说明月度调仓下，约 2 周周期的短期情绪过度反应修复最剧烈，周期拉长后反转动能边际递减。

### 3.3 基本面因子的月度局限
* `roe` 月度 IC 仅为 0.0051，表明低频季度财报直接用于月度轮动时容易受短期情绪冲击钝化，后续需与估值指标（PB）构建 PB-ROE 复合模型。

## 4. 核心因子异质性检验 (以 `amt_mean_20d` 为例)

### 4.1 市场状态异质性 (Bull vs. Bear)
* **牛市 (`Bull`)**：IC 均值 **0.0906**，IR **0.6382**，胜率 **80.85%**。
* **熊市 (`Bear`)**：IC 均值 **0.0697**，IR **0.4717**，胜率 **63.64%**。
* **结论**：缩量反转因子全天候有效，但在牛市板块轮动加速时爆发力与胜率最高。

### 4.2 行业板块异质性 (Industry)
* **其他/中小盘 (`Others`)**：IC **0.0883**，胜率 **72.50%**。
* **科技成长 (`Growth/Tech`)**：IC **0.0716**，胜率 **68.75%**。
* **大金融权重 (`Finance/LargeCap`)**：IC **0.0567**，胜率 **61.25%**。
* **结论**：定价效率较低、散户博弈激烈的中小盘与科技板块反转 Alpha 空间显著大于机构重仓的金融蓝筹。

## 5. 第四阶段推进建议
1. 构建 $PB\text{-}ROE$ 估值质量复合得分，改善基本面因子低频失效问题。
2. 引入 **IC-IR 动态加权** 与 **最大化复合 IR 优化模型** 构建多因子投资组合。
3. 引入行业与市值中性化风控约束，锁定纯净 Alpha 收益。
