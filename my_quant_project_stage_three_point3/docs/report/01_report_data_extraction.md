# 阶段一：全市场底层行情数据抽取与数据流清洗报告

## 1. 实验目标与数据源
* **数据源**：本地 MongoDB 数据库（`quantaxis.stock_day` 集合）。
* **覆盖范围**：A 股全市场 5,158 只股票的历史日线量价数据。
* **时间跨度**：2020 年 1 月 1 日至 2026 年 12 月 31 日。
* **核心目标**：实现全市场历史行情的高效分年抽取、动态缓冲区回溯计算、异常值初筛与轻量化落盘。

## 2. 核心实验设计与处理流程

### 2.1 跨年滚动缓冲区设计 (Buffer Window)
为了计算跨年首月的滚动指标（如 10 日、20 日动量），避免每年首月由于历史数据截断产生空值，引入前置滚动缓冲机制：
* **提取区间**：每年设定缓冲起始日为前一年的 `11月15日`（如处理 2021 年数据时，提取 `2020-11-15` 至 `2021-12-31`）。
* **窗口计算**：在包含缓冲区的完整时间序列上计算 `mom_10` 与 `mom_20`。
* **截断落盘**：计算完成后截断剔除前置缓冲区行，仅保留目标年份数据写入最终数据集。

### 2.2 内存管理与落盘优化
* **分年批次流式写入**：采用逐年追加写入模式（`mode='a'`），单年计算完成后显式触发 Python 垃圾回收机制（`gc.collect()`），防止全量多周期数据同时驻留内存导致内存溢出。
* **文件落盘格式**：CSV 格式存储，采用 UTF-8-SIG 编码保证中文字符兼容。

## 3. 数据清洗规则与结果统计
* **停牌与空值处理**：通过 `dropna()` 剔除新股上市初期及长期停牌产生的因子缺失行。
* **异常收益率截断**：过滤掉由于除权除息未对齐或数据脏乱产生的异常极端值。
* **有效落盘样本量**：全市场 2020~2026 年累计清洗有效数据量约数百万行。

## 4. 阶段产出与后续节点对接
* **输出成果物**：`data/processed/factor_all_history.csv`
* **后续对接**：该底座数据直接为阶段二的前复权计算与月度降频截面提供量价输入源。
