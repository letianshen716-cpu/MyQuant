# 阶段三：单因子有效性检验、正交化与异质性报告

## 1. 预处理与去共线性
* **去极值与标准化**：对横截面执行三倍中位绝对离差法 (3.0 × MAD) 去极值，并辅以 Z-score 标准化。
* **对称正交化 (Symmetric Orthogonalization)**：利用矩阵特征值分解构造正交变换矩阵 $S$，消除了因子间的线性共线性，确保合成前信号纯净。
* **智能 Lasso 保护机制**：针对低信噪比金融数据，当输入高质量因子 $\le 10$ 时，触发保护机制跳过 Lasso 惩罚，防止核心正交信号被误杀归零。

## 3. 实证规律与异质性归因
1. **缩量溢价主导**：A 股市场散户情绪驱动明显，前期极度缩量滞涨的冷门股，在次月发生均值回归的动能最强。
2. **反转期限衰减**：10日反转显著优于20日反转，证明 A 股情绪修复最剧烈的窗口在 2 周左右。
3. **行业异质性**：以 10日反转 为例，其在 `Others` (中小盘) 中的 IC 达 0.0526，而在 `Finance/LargeCap` (大金融) 中仅为 0.0248，验证了定价效率低的板块更易产生反转 Alpha。
