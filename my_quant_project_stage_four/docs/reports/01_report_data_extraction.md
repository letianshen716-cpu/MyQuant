# 阶段一：底层数据抽取与量价历史因子提取报告

## 1. 实验目标与背景
* **研究背景**：构建多因子模型需要海量的历史量价数据作为底座。直接在内存中全量拉取极易导致 OOM (内存溢出) 和数据库断连。
* **实验目标**：实现全市场日线行情的高效流式抽取、异常值初筛与轻量化落盘，并解决跨年计算滚动指标时因数据截断导致的空值问题。
* **数据源与跨度**：本地 QUANTAXIS 数据库 `stock_day` 集合，覆盖 A 股全市场，时间窗口为 2020-01-01 至 2026-12-31。

## 2. 核心实验设计与处理流程
### 2.1 跨年滚动缓冲区 (Buffer Window) 机制
为确保每年 1 月份的动量指标（如 10 日、20 日收益率）能够正常计算，引入前置缓冲区：
* **提取区间**：遍历每年数据时，提取起点向前回溯至上一年的 `11-15`。
* **指标计算**：在包含缓冲区的连续时间序列上计算 `mom_10` 与 `mom_20`，避免了年初由于无历史数据产生的 `NaN`。
* **截断落盘**：计算完成后，严格按 `YYYY-01-01` 截断前置缓冲区，确保落盘数据无冗余。

### 2.2 内存流式管理
* 采用逐年提取、逐年追加（`mode='a'`）写入 CSV 的模式。
* 单年数据处理完毕后，强制调用 `del` 与 `gc.collect()`，将峰值内存控制在安全水位。

## 3. 实验数据输出
* **落盘文件**：`data/processed/factor_all_history.csv`
* **有效性说明**：清洗并移除了大量上市初期及长期停牌产生的空值，最终落地数百万行有效日线因子序列，为第二阶段的截面降频提供坚实底座。
