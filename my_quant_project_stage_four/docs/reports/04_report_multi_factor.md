# 阶段四：多因子加权合成、组合回测与稳健性报告

## 1. 组合构建与回测约束
* **选股与权重**：依据合成得分选取截面 Top 50 股票，采取等权重 (Equal Weight) 分配仓位。
* **真实约束**：内置换手率追踪，执行严格的 0.3% 双边交易摩擦成本扣除。

## 2. 因子加权方案对比 (全样本：2020-2026)

| 加权方案 | 年化收益 (CAGR) | 夏普比率 (Sharpe) | 最大回撤 (MDD) | 结果分析 |
| :--- | :---: | :---: | :---: | :--- |
| **等权基准 (Equal Weight)** | **10.73%** | **0.33** | **37.7%** | **最优方案**。参数估计误差为0，鲁棒性最强。 |
| **动态 IC-IR 加权** | 3.65% | 0.07 | 41.6% | 表现平庸，滞后性削弱了反转因子的短期爆发力。 |
| **最大化复合 IR 优化** | -12.54% | -0.51 | 73.7% | **等权之谜 (Equal Weight Puzzle)**：协方差矩阵求逆放大了低信噪比市场的噪音，导致权重畸变崩溃。 |

## 3. 子区间稳健性压力测试 (基于等权最优模型)
* **2020-2022 震荡分化期**：年化收益 **16.25%**，夏普比率 0.54。依靠低波动与缩量因子展现了极强的逆市抗跌与抄底能力。
* **2023-2026 轮动修复期**：年化收益 **20.36%**，夏普比率 0.68。模型高效捕获了流动性恢复期的市场轮动 Alpha。

## 4. 局限性与后期优化建议
* **极高的换手损耗**：回测显示组合月均换手率高达 97.8%。摩擦成本吞噬了理论毛收益（Gross Return）约 7% 的绝对空间。
* **优化方向**：下一阶段研发应聚焦于降低组合换手率。可通过引入“换手率惩罚约束”或“双边阈值调仓法”（持仓未跌出前 20% 不主动卖出），以保留大部分 Alpha 的同时大幅削减交易成本。
