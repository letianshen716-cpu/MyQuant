# 第一阶段：量化研究框架认知与研究样本体系搭建

## 1. 项目简介
本项目目前聚焦于量化投研的第一阶段：核心目标是确立量化研究的标准范式，并搭建自动化、可复用的底层数据获取与存储架构。本阶段完成了从多源公开数据的拉取、数据库连接池的配置，到最终研究样本池（2020-2026年）的质量校验与基线确立，为后续的特征工程与归因分析打造了纯净的数据底座。

## 2. 核心架构与目录
* **`config/`**：【独立配置层】集中管理动态相对路径、数据库 URI 与研究基线参数。
* **`data/`**：【数据存储层】`raw_data/` 存放第一阶段拉取的原始行情与财务报表。
* **`docs/reports/`**：【文档与报告层】记录量化业务逻辑、数据接入日志与样本质量基线评估结论。
* **`src/`**：【核心算法层】封装底层数据获取引擎（支持按年切片加载防OOM）与数据质量校验引擎。
* **`scripts/`**：【执行脚本层】包含环境初始化、自动化拉取流水线及基线偏差识别。

## 3. 环境配置与启动指南

**第一步：安装依赖**
```bash
pip install -r requirements.txt
```

**第二步：按序执行第一阶段**
```bash
# 1. 初始化动态目录树与数据库连接测试
python scripts/01_setup_project_env.py

# 2. 按年度分批次自动化拉取历史行情数据与财务数据入库
python scripts/02_download_market_data.py

# 3. 对入库数据进行基础偏差识别，生成质量评估报告
python scripts/03_validate_sample_quality.py
```
