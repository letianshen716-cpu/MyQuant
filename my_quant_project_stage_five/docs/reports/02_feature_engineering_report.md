# 节点 2：前复权处理、行业映射与 PIT 截面对齐记录

## 1. 价格序列的前复权处理 (QFQ)
在计算技术面因子（如动量、波动率）时，分红派息会导致价格序列出现向下跳空的“断层”。
*   **处理方案**：全局采用**前复权（QFQ, Forward-Adjusted）**价格进行特征工程计算。确保了历史价格曲线的连续性，使得 $t$ 期的动量因子能够真实反映投资者的实际资本利得。

## 2. 行业板块宽表映射
为后续的异质性分析与行业中性化打下基础，将全市场数千只标的映射为更具统计学意义的宏观板块：
*   **Finance/LargeCap (大金融/大蓝筹)**：包含银行、证券、保险及部分超大市值基建。
*   **Growth/Tech (成长/科技)**：包含软件、半导体、通信、电子等（通常覆盖科创、创业板核心标的）。
*   **Manufacturing (传统制造)**：机械、汽车、化工等。
*   **Others (中小盘/其他)**：不属于上述特征的其他中小市值周期或消费股。

## 3. 核心机制：PIT (Point-in-Time) 财报防前视偏差对齐
**前视偏差 (Look-ahead Bias)** 是基本面量化中最致命的错误。本研究严格执行了向后安全期对齐逻辑，坚决杜绝“用未来的财报选今天的股”。
*   **对齐规则**：基于国内 A 股法定披露截止日，强行施加信息滞后：
    *   一季报 (03-31) $\rightarrow$ 锁定至 05-01 可见。
    *   中报 (06-30) $\rightarrow$ 锁定至 09-01 可见。
    *   三季报 (09-30) $\rightarrow$ 锁定至 11-01 可见。
    *   年报 (12-31) $\rightarrow$ 锁定至次年 05-01 可见。
*   **技术实现**：使用 Pandas 的 `merge_asof(direction='backward')` 进行时序拼接，确保截面选股时，调用的绝对是**最新且已公开**的财务指标（如 ROE）。
