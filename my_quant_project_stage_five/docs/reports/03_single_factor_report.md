# 节点 3：单因子去极值、正交化、Lasso降维及异质性

## 1. 因子去极值与标准化
为了防止极端偏态数据（如某些微盘股极高的换手率或畸形的 ROE）破坏线性模型，执行以下步骤：
*   **MAD 去极值 (Winsorization)**：
    计算因子的绝对中位差 $MAD = Median(|X_i - Median(X)|)$。设定阈值范围：
    $$X_{clip} = \min(\max(X, Median - 3.0 \times MAD), Median + 3.0 \times MAD)$$
*   **Z-score 标准化**：
    将因子映射到标准正态空间，消除量纲影响：
    $$Z = \frac{X - \mu}{\sigma}$$

## 2. 多重共线性消除与特征降维
*   **对称正交化 (Symmetric Orthogonalization)**：针对高度相关的动量因子（10日与20日动量），通过求解协方差矩阵的特征值分解，提取纯正交信号，防止回测时权重过度集中。
*   **LassoCV 动态筛选**：引入 $L_1$ 正则化惩罚项进行特征降维，过滤掉截面解释力弱的因子，最终锁定 `momentum_10d`, `volatility_20d`, `amt_mean_20d` 为核心驱动因子。

## 3. 单因子实证与异质性发现
根据实证数据（Rank IC 与多空收益测试），得出以下核心结论：
1.  **缩量溢价极强**：`amt_mean_20d` (低均量) 因子展现出惊人的预测力（多空收益差 2.02 倍，胜率 75.95%），印证了 A 股“无人问津处藏牛股”的反转逻辑。
2.  **基本面因子的高频失效**：静态 `roe` 因子在月度级别的量价博弈中几乎无 Alpha 预测能力 (IC=0.0061)。
3.  **异质性分化 (Heterogeneity)**：反转因子在 `Others`（中小盘）中表现极其优异 (IC 均值 0.0526，胜率 78.7%)；但在 `Finance/LargeCap` (大蓝筹) 中完全失效 (胜率不足 50%)。
