# 节点 1：底层数据抽取、去停牌与清洗规则说明

## 1. 数据集定义与覆盖范围
*   **数据范围**：A 股全市场 A 股（剔除北交所、科创板初期数据以保持回测平稳性）。
*   **时间窗口**：2020-01-01 至 2026-12-31，共计 7 年全样本数据。
*   **数据源**：依托本地 QUANTAXIS 数据库，提取日线级别的量价数据（OHLCV）与低频的财务报表数据。

## 2. 异常标的过滤规则
在构建初始股票池时，为避免策略在实盘中遭遇流动性危机或退市风险，严格执行以下过滤条件：
*   **剔除 ST/PT 标的**：剔除面临退市风险警示的股票。
*   **剔除停牌标的**：当日无交易量（`Volume == 0`）或长期停牌的股票不计入横截面因子计算。
*   **剔除新股（上市不满 6 个月）**：次新股存在极高的新股溢价与波动率噪音，不纳入统计样本。

## 3. 缺失值 (NaN) 清洗策略
由于财务数据披露存在天然的时滞和遗漏，对于因子计算后产生的缺失值，采用以下递进式清洗方案：
1.  **行业截面中位数填补**：针对单只股票的缺失因子，使用横截面上同行业（依据通达信/同花顺二级行业划分）的中位数进行填补，以保留其行业特征。
2.  **全市场中位数兜底**：若某行业在特定截面上数据全部缺失，则降级使用全市场中位数进行兜底。
3.  **极值剔除**：直接剔除收益率异常（如下一月收益率 $R_{t+1} > 2.0$ 或 $R_{t+1} < -0.5$）的错位样本。
